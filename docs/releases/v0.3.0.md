# Asterveil v0.3.0

本版本把各项页面增强统一收进“辅助功能”大开关，首页布局改为在页面上直接调整，并更新内置姓名数据。提供普通版 Asterveil 和 Asterveil Pro，Pro 版额外支持 Markdown 编辑器的 PDF 导出、上传与提交。

## 更新内容

- **辅助功能总开关**：Markdown 编辑器、“复制题面与标题”“复制提交代码”“榜单筛选”“模测复盘入口”“登录与账号页”“操作提示”“聊天 Markdown”统一归入“功能模块 → 辅助功能”，按“编辑”“复制”“筛选与目录”“页面整理”“提示”“聊天”分组排列小开关；关闭总开关即停用全部子功能，各子开关保留独立状态。
- **设置面板重排**：导航顺序改为“Better Names → 功能模块 → 外观配色 → 关于”。“外观配色”放界面美化、显示模式、主题配色与自定义背景；“功能模块”放辅助功能卡片与头像替换卡片；子开关按三列等宽排列，卡片之间间距统一。
- **首页布局页内编辑**：去掉独立模块和设置页面板，首页左上角（固定于站点导航下方）提供调整入口。进入编辑后可拖动板块把手跨左右栏排序，显示插入横线；板块可单独隐藏或恢复；拖到屏幕上下边缘时自动滚动；支持键盘方向键移动、Home / End 移到首尾、Esc 结束，点击“完成”或“恢复默认”即时保存。
- **点击水波纹**：鼠标左键点击页面时出现浅色波纹，向外扩散并快速消散，触到视口边缘时反射；尊重系统“减少动态效果”设置，随总开关停用。
- **自定义背景**：改为图片预览卡片，选择后显示背景图，鼠标悬停时右上角出现删除按钮；未选择时显示图片占位按钮，点击选择图片，已选后点击预览可更换。
- **关于页**：作者显示“鱼oe不缺氧 & for_fo_f”，版本号显示为 `v0.3.0-f` 以区分非原版；“版本更新”卡片仅保留 fork 说明，暂不提供自动更新入口，更新器代码保留以便后续恢复。
- **Better Names 数据**：内置官方名单更新为 3,587 条，并合并个人好友与 Better Names 计划名单。内置数据改为按高中毕业年份保存，运行时按当前学年（每年 9 月 1 日切换）推算年级与配色；名单解析同时支持 `graduateYear` 字段。
- **体验修复**：移除“外观配色”中重复的头像替换入口；主题配色与自定义背景在默认宽度下并排等高；设置卡片与开关的键盘操作、焦点样式保持一致。

## 下载与安装

| 文件 | 用途 |
| --- | --- |
| `Asterveil-0.3.0-chrome.zip` | 普通版，仅插件 |
| `Asterveil-Pro-0.3.0-chrome.zip` | Pro 版，仅插件，包含 PDF 功能 |
| `Asterveil-0.3.0-chrome-with-updater.zip` | 普通版，包含更新器 |
| `Asterveil-Pro-0.3.0-chrome-with-updater.zip` | Pro 版，包含更新器 |
| `SHA256SUMS.txt` | 安装包 SHA-256 校验值 |
| `update-manifest.json`、`update-manifest.sig` | 自动更新清单及 Ed25519 签名 |

已有用户可更新原加载目录，在扩展管理页重新加载，再刷新 7FA4 页面；先保存当前未提交的代码和作业草稿。设置、自定义配色与导入名单继续保留；旧版“复制题面”“首页布局”“界面微调”模块开关会被忽略或迁移到新的辅助功能子开关。含更新器的包加载其中的 `extension` 文件夹；更新器安装说明见仓库 [README](https://github.com/DestinyleSnowy/Asterveil#readme)。
